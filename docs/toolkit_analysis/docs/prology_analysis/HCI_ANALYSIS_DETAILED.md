## 📶 BLE АНАЛИЗ

### Обнаруженные сервисы

**Handle 0x0018** - Основной сервис уведомлений  
**Handle 0x0016** - Сервис записи команд  
**Handle 0x001D** - Сервис информации

### Формат пакетов

Все пакеты начинаются с `0x6F` и заканчиваются `0x8F` - это сигнатура протокола PROLOGY!

#### Структура пакета:
```
┌──────┬──────┬──────┬──────┬────────┬────────┬──────┐
| 0x6F | CMD  | SUB  | LEN  | DATA   | CHECK? | 0x8F │
└──────┴──────┴──────┴──────┴────────┴────────┴──────┘
  1 byte 1 byte 1 byte 1 byte  N bytes 1 byte   1 byte
```

### Активность SPP

- Передачи аудио (A2DP)
- Управления устройством
- Синхронизации настроек

## 🎯 ПРОТОКОЛ PROLOGY - ДЕТАЛИ

### Сигнатура протокола

**Все пакеты:**
- Начинаются с `0x6F`
- Заканчиваются `0x8F`

### Формат команд

```
Запрос:
┌──────┬──────┬──────┬──────┬────────┬──────┐
| 0x6F | CMD  | 0x70 │ LEN  │ DATA   | 0x8F │
└──────┴──────┴──────┴──────┴────────┴──────┘

Ответ:
┌──────┬──────┬──────┬──────┬────────┬──────┐
| 0x6F | CMD  │ 0x80 │ LEN  │ DATA   | 0x8F │
└──────┴──────┴──────┴──────┴────────┴──────┘
```

**Байты:**
- `0x6F` - Заголовок (SYNC)
- `CMD` - Код команды
- `0x70` - Запрос / `0x80` - Ответ
- `LEN` - Длина данных
- `DATA` - Полезная нагрузка
- `0x8F` - Конец пакета (END)

### Таблица команд

| CMD | Название | Описание | Пример данных |
|-----|----------|----------|---------------|
| 0x03 | XOVER | Настройки кроссовера | `LS20` (модель) |
| 0x08 | BASS_TREBLE | Bass/Treble настройки | `0x58` (уровень) |
| 0x0F | VOLUME | Громкость | `0x01` (уровень) |
| 0x11 | SUBWOOFER | Сабвуфер / имя устройства | `JW_LS20WF0151` |
| 0x43 | EQ_SETTINGS | Настройки эквалайзера | 13 байт данных |
| 0x93 | DEVICE_INFO | Информация об устройстве | Серийный номер |
| 0xBE | BLUETOOTH | Сопряжённые устройства | MAC адреса |

## 🔐 ВЫЯВЛЕННЫЕ УЯЗВИМОСТИ

### 1. **Отсутствие шифрования**
- Все команды передаются в открытом виде
- Можно перехватить и проанализировать

### 2. **Нет аутентификации**
- Любое устройство может отправить команду
- Нет проверки подлинности

### 3. **Предсказуемый протокол**
- Простая структура пакетов
- Сигнатура `6F xx 8F` легко распознаётся

### 4. **Нет проверки целостности**
- Checksum не обнаружен
- Можно подделать пакеты

## 🛠 ПРИМЕРЫ КОМАНД ДЛЯ ОТПРАВКИ

### Python (BLE)

```python
from bleak import BleakClient

ADDRESS = "XX:XX:XX:XX:XX:XX"
WRITE_HANDLE = 0x0016
NOTIFY_HANDLE = 0x0018

async def send_command(client, cmd, subcmd, data):
    """Отправка команды устройству"""
    packet = bytes([0x6F, cmd, subcmd, len(data)]) + data + bytes([0x8F])
    await client.write_gatt_char(WRITE_HANDLE, packet)
    
async def get_device_info(client):
    """Запрос информации об устройстве"""
    await send_command(client, 0x93, 0x70, bytes([0x00, 0x00]))
    
async def set_volume(client, volume):
    """Установка громкости (0-100)"""
    await send_command(client, 0x0F, 0x70, bytes([0x01, volume]))
    
async def get_eq_settings(client):
    """Запрос настроек эквалайзера"""
    await send_command(client, 0x43, 0x70, bytes([0x00, 0x01]))

async with BleakClient(ADDRESS) as client:
    await get_device_info(client)
    await set_volume(client, 50)
```

### Python (SPP)

```python
import bluetooth

MAC = "XX:XX:XX:XX:XX:XX"

sock = bluetooth.BluetoothSocket(bluetooth.RFCOMM)
sock.connect((MAC, 1))

# Отправка команды
def send_cmd(cmd, data):
    packet = bytes([0x6F, cmd, 0x70, len(data)]) + data + bytes([0x8F])
    sock.send(packet)
    
# Запрос информации
send_cmd(0x93, [0x00, 0x00])
response = sock.recv(1024)
print(f"Ответ: {response.hex()}")
```

## 📋 РЕКОМЕНДАЦИИ

### Для разработчиков PROLOGY

1. **Добавить шифрование**
   - Использовать AES-128 для шифрования пакетов
   - Уникальный ключ для каждого устройства

2. **Аутентификация**
   - Challenge-Response механизм
   - HMAC подпись команд

3. **Проверка целостности**
   - CRC-16 или CRC-32 для каждого пакета
   - Sequence number для защиты от replay атак

4. **Rate Limiting**
   - Ограничение на количество команд в секунду
   - Защита от DoS

### Для исследователей

1. **Перехват трафика**
   - Использовать Ubertooth или Ellisys
   - Анализ в Wireshark

2. **Фаззинг**
   - Перебор всех CMD (0x00-0xFF)
   - Поиск undocumented команд

3. **Реверс прошивки**
   - Дамп-flash MCU
   - Анализ кода протокола
